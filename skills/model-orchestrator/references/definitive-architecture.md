# Definitive architecture

Traycer coordinates one Codex orchestration session. Codex reads GSD, decomposes phases, classifies, contracts, selects workers, requests agents, monitors handoffs, reviews independently, and integrates approved results. It retains architecture, security, sensitive, cross-cutting, and critical work.

Every external development worker uses OpenCode for files, terminal, tests, authorized worktree, allow/deny lists, and handoff. MiMo uses `opencode/mimo-v2.5-free`. OpenRouter supplies only `openrouter/deepseek/deepseek-v4-flash-0731` and `openrouter/poolside/laguna-s-2.1`; it is not a harness or agent.

MiMo: simple, low-risk, sanitized/synthetic, small and objectively verifiable; one attempt. DeepSeek: bounded endpoints, components, tests, refactors, adapters, and ordinary implementation. Laguna: intensive terminal, debugging, repository navigation, tool calls, iterative tests, and longer agentic execution.

Each child requires function, contract, model, harness, surface, worktree, allowlist, denylist, attempt/cost limits, acceptance criteria, and handoff format. Reject parallel execution on overlapping files or areas.
